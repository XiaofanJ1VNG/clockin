# Your tap timer

This little NFC tag is a stopwatch for freelance work. Tap it, it starts timing. Tap it again (or just come back to the link), stop it, tell it which project it belongs to. That's the whole thing.

No app to download, no account to make, nothing to remember. The tag *is* the login.

## How to use it

**Tap the tag with your phone.** It opens a link in your browser and the timer starts right away — no buttons to press first.

**Do your work.** Leave the tab open or close it, doesn't matter, the clock keeps running either way.

**Tap the tag again (or open the same link) when you're done.** Hit **Stop**. It'll show you how long you worked and ask which project to file it under — pick one from the list, or create a new one on the spot.

That's it. Your sessions build up in a running log underneath, with a total for each project.

## A few things you can do besides tap-to-track

- **+ Add project** — set up a project ahead of time, so it's ready to pick from later.
- **+ Add entry** — forgot to tap the tag, or worked somewhere without it? Add a session manually: pick the project, set the date and the clock-in/clock-out times, and it'll calculate the duration for you.
- **Edit any entry** — click "Edit" next to any log entry to fix the times, the date, or move it to a different project.
- **Delete an entry** — click "Delete" if something got logged by mistake.
- **Export to CSV** — pick a project (or "All projects") and download a spreadsheet-ready file with the date, clock-in, clock-out, and duration for every session. Handy for invoicing.

## One thing worth knowing

This link is private, but not password-protected — the privacy comes from the link itself being just yours. Don't post it publicly or forward it to people you don't want poking around in your hours. Totally fine to lose the physical tag though; the link still works from anywhere, the tag is just a shortcut to it.

If you ever want to check your log from a different phone or a laptop, just open the exact same link there — same data, no separate login needed.

Enjoy, and hope it makes tracking your time a little less annoying.
